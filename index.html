    📚 基礎化學知識

    ⚛️ 原子的基本結構（香港中學課程）

    原子 (Atom) 是化學反應中的最小粒子，由以下三種微粒組成：

    • 質子 (Proton, p⁺)：帶正電荷 (+1)，位於原子核中，質量 ≈ 1 u。質子數 = 原子序 (Z)
    • 中子 (Neutron, n⁰)：不帶電荷 (0)，位於原子核中，質量 ≈ 1 u。中子數 = A - Z
    • 電子 (Electron, e⁻)：帶負電荷 (-1)，繞原子核運動，質量可忽略 (≈ 0.0005 u)

    📐 電子排佈（Electron Arrangement）

    電子殼層 (Electron Shells)

    • K 層 (第1層)：最多容納 2 個電子，最接近原子核
    • L 層 (第2層)：最多容納 8 個電子
    • M 層 (第3層)：最多容納 18 個電子
    • N 層 (第4層)：最多容納 32 個電子
    • 規則：最外層電子不超過 8 個（八隅體規則），K層例外（最多2個）

    電子組態表示法 (Electronic Configuration)：
    例：鈉(Na, Z=11) → 2,8,1 或 [Ne]3s¹
    例：氯(Cl, Z=17) → 2,8,7 或 [Ne]3s²3p⁵
    例：鈣(Ca, Z=20) → 2,8,8,2 或 [Ar]4s²

    🔢 同位素 (Isotopes)

    同位素定義：質子數相同但中子數不同的同一元素原子。

    • 質子數(Z) 決定元素種類（同位素 Z 相同）
    • 中子數(N = A - Z) 不同 → 質量數不同
    • 化學性質幾乎相同（因電子結構相同）
    • 物理性質不同（如密度、放射性）

    常見例子：
    🔹 氫的同位素：氕(¹H)、氘(²H或D)、氚(³H或T)
    🔹 碳的同位素：¹²C(98.9%)、¹³C(1.1%)、¹⁴C(微量，具放射性)
    🔹 氯的同位素：³⁵Cl(75%)、³⁷Cl(25%) → 平均原子量 35.45

    🔗 化學鍵類型（Chemical Bonding）

    類型形成條件特點例子
    離子鍵 (Ionic)金屬 + 非金屬電子轉移 → 離子NaCl, MgO
    共價鍵 (Covalent)非金屬 + 非金屬共用電子對H₂O, CO₂, CH₄
    金屬鍵 (Metallic)金屬原子之間自由電子海Fe, Cu, Na

    電負性差 (Electronegativity Difference)：

    • 差值 > 1.7 → 主要為離子鍵
    • 差值 0.4 ~ 1.7 → 主要為極性共價鍵
    • 差值 < 0.4 → 非極性共價鍵
    • 差值 = 0 → 純非極性共價鍵（同種元素）

    ⚛️ σ鍵 vs π鍵 (Sigma & Pi Bonds)

    共價鍵的兩種類型：

    • σ 鍵 (sigma bond)：頭對頭(head-to-head)重疊
      • 電子雲沿核間軸線對稱分佈，重疊程度最大
      • 所有單鍵都是 σ 鍵；雙鍵/三鍵中也有 1 個 σ 鍵
      • 可自由旋轉（不影響鍵強度）
    • π 鍵 (pi bond)：平行側面(side-by-side)重疊
      • 電子雲在核間軸線上下方，重疊程度較小
      • 只存在於雙鍵(1個π)和三鍵(2個π)中
      • 不能自由旋轉（會破壞π鍵重疊）
      • 比 σ 鍵弱，容易斷裂（如加成反應）

    例子：C₂H₄(乙烯)：C=C = 1σ + 1π | C₂H₂(乙炔)：C≡C = 1σ + 2π

    🔢 化合價與化學式 (Valency)

    • 化合價 (Valency)：元素形成化合物時結合的原子數目能力
    • 常見化合價：H(+1), O(-2), Na(+1), Ca(+2), Al(+3), Cl(-1), NH₄⁺(+1), OH⁻(-1)
    • 寫化學式原則：「正前負後、交叉約簡」
    • 例：Al³⁺ + SO₄²⁻ → Al₂(SO₄)₃
    • 氧化數規則：
      • 單質中元素氧化數為 0
      • 化合物中各元素氧化數代數和為 0
      • 離子團中各元素氧化數代數和等於離子電荷
      • O 通常為 -2，H 通常為 +1（過氧化物中 H 為 -1）

    常見酸：HCl(鹽酸), H₂SO₄(硫酸), HNO₃(硝酸), CH₃COOH(醋酸,弱酸)

    常見鹼：NaOH(氫氧化鈉), Ca(OH)₂(氫氧化鈣), NH₃·H₂O(氨水,弱鹼)

    📊 pH 值與指示劑（pH Scale & Indicators）

    • pH = -log[H⁺]，範圍 0 ~ 14
    • pH < 7 → 酸性（pH 越小越酸），pH > 7 → 鹼性（pH 越大越鹼）
    • pH 每減少 1 → [H⁺] 增大 10 倍

    常用指示劑：

    • 石蕊試紙 (Litmus)：紅色→酸性 / 藍色→鹼性（只能判斷酸鹼）
    • 酚酞 (Phenolphthalein)：無色(酸/中性) → 粉紅色(鹼, pH>8.2)，常用於中和滴定終點
    • 通用指示劑 (Universal Indicator)：可顯示不同pH值的顏色變化（紅→橙→黃→綠→藍→紫）
    • 甲基橙 (Methyl Orange)：紅色(pH<3.1) → 橙色(pH 3.1~4.4) → 黃色(pH>4.4)

    ⚖️ 中和作用（Neutralization）

    定義：酸 + 鹼 → 鹽 + 水 + 熱量（放熱反應）

    通式：Acid + Base → Salt + H₂O + Energy

    例子：

    • HCl + NaOH → NaCl + H₂O（氯化鈉 + 水）
    • H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O（硫酸鈉 + 水）
    • 2HCl + Ca(OH)₂ → CaCl₂ + 2H₂O（氯化鈣 + 水）
    • CH₃COOH + NaOH → CH₃COONa + H₂O（醋酸鈉 + 水）

    ⚠️ 注意：強酸+強鹼完全中和時 pH=7；弱酸+強鹼 pH>7；強酸+弱鹼 pH<7

    🔄 氧化還原反應（Redox Reactions）

    口記：OIL RIG → Oxidation Is Loss（氧化是失去電子），Reduction Is Gain（還原是獲得電子）

    過程電子變化氧化數角色
    氧化 (Oxidation)失去電子 e⁻↑ 升高還原劑(Reducing agent)
    還原 (Reduction)獲得電子 e⁻↓ 降低氧化劑(Oxidizing agent)

    常見例子：

    • 🔥 燃烧：C + O₂ → CO₂（C被氧化，O被还原）
    • 🔋 電池：Zn + CuSO₄ → ZnSO₄ + Cu（Zn被氧化，Cu²⁺被還原）
    • ⚡ 銹蝕：4Fe + 3O₂ → 2Fe₂O₃（Fe 被氧化，Fe²⁺/Fe³⁺ 是氧化產物）

    ⚡ 電化學系列與電解（Electrochemistry & Electrolysis）

    電化學系列 (Electrochemical Series) — 活潑性由高至低：

    K > Na > Ca > Mg > Al > Zn > Fe > Ni > Sn > Pb > H > Cu > Ag > Au > Pt

    • 排在 H 前面的金屬能與酸反應產生氫氣
    • 排在前面的金屬能把排在後面的金屬從其鹽溶液中置換出來
    • 越活潑的金屬越容易失去電子（被氧化）

    電解原理：

    • 陽極 (Anode, +)：發生氧化反應，陰離子或活性電極失電子
    • 陰極 (Cathode, -)：發生還原反應，陽離子得電子
    • 電解濃 NaCl 溶液：
      陽極(+)：2Cl⁻ → Cl₂↑ + 2e⁻ | 陰極(-)：2H₂O + 2e⁻ → H₂↑ + 2OH⁻
      總反應：2NaCl + 2H₂O → 2NaOH + H₂↑ + Cl₂↑

    💨 氣體定律（Gas Laws）

    定律公式條件說明
    波義耳 (Boyle's)P₁V₁ = P₂V₂恆溫(T)壓強與體積成反比
    查理 (Charles')V₁/T₁ = V₂/T₂恆壓(P)體積與溫度(K)成正比
    理想氣體PV = nRT一般情況R = 8.314 J/(mol·K)

    重要常數：

    • R = 8.314 J/(mol·K) = 0.0821 L·atm/(mol·K)
    • 標準狀況 STP：0°C (273 K), 1 atm → 1 mol 氣體 = 22.4 L
    • 室溫 RTP：25°C (298 K), 1 atm → 1 mol 氣體 = 24.0 L（或24.5L）

    📏 摩爾概念與摩爾體積（Mole & Molar Volume）

    • 摩爾 (mole, mol)：物質的量的單位。1 mol 含有 阿伏伽德羅常數 (Nₐ = 6.02 × 10²³) 個粒子
    • 摩爾質量 (Molar Mass, M)：以 g/mol 為單位時，數值等於相對原子/分子質量
    • 摩爾體積 (Molar Volume, Vₘ)：
      • STP 下：Vₘ = 22.4 L/mol
      • RTP 下：Vₘ = 24.0 L/mol
    • 重要公式：
      • n = m / M （摩爾數 = 質量 ÷ 摩爾質量）
      • n = V / Vₘ （摩爾數 = 體積 ÷ 摩爾體積）
      • C = n / V （濃度 = 摩爾數 ÷ 體积(L)），單位 mol/L 或 M
